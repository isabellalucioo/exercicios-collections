# Exercícios de Collections em Java

Este repositório reúne exercícios desenvolvidos durante meus estudos de Java sobre Collections, Comparable e Ordenação de Listas
## 🛠 Tecnologias utilizadas

- Java
- IntelliJ IDEA

## 📚 Conceitos praticados

- Collections
- Map e HashMap
- Interface Comparable

## 📂 Exercícios

Os exercícios abordam diferentes desafios, como:

- Criação de lista aplicando polimorfismo
- Uso de for each
- Implementar Comparable em uma Classe
- Adicionar e imprimir objetos em uma Lista
